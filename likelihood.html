CONFIGURATION REFERENCE

Likelihood

The Likelihood Interface defines how the model prediction is constructed and compared with the measurement. It connects the input datasets, parameter propagation, and joint probability calculation.

Main Structure

The Likelihood Interface brings together three central pieces of the fit.

Datasets
model and measurement inputs
Propagator
apply parameter effects
Joint Probability
compare model and data

Datasets

dataSetList defines the input datasets used for the model and measurement.

Dataset configuration remains part of the Likelihood workflow rather than being introduced as another navigation level.

Propagator

propagatorConfig configures the component responsible for applying fit-parameter variations to the model prediction.

Propagator

Configure samples, parameters, event loading, and parameter propagation.

Joint Probability

jointProbabilityConfig defines the statistical comparison between the measurement and the model prediction.

The configuration block is forwarded to the selected joint probability implementation.

Option Type Description Default
ignoreBinsWithZeroPredictionAtPrior bool Ignore bins whose model prediction is zero at the prior during likelihood evaluation. false
