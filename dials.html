CONFIGURATION REFERENCE

Dials

Dials define how variations of fit parameters modify the model prediction. They provide the connection between parameter values and the resulting response applied to events or samples.

How Dials Are Used

A fit parameter can be associated with one or more dials. As the parameter changes during the fit, the corresponding dial evaluates the response and modifies the model prediction.

Fit Parameter
→
Dial
→
Event weight
or model response

This separation allows the parameter definition and the model response to remain conceptually distinct. A parameter describes what is varied, while a dial describes how that variation affects the prediction.

Dial Types

GUNDAM supports several dial implementations for different kinds of model responses.

Dial Type Purpose
Normalization Applies a normalization-style response.
Graph Evaluates a response defined by graph points.
Spline Interpolates a one-dimensional response curve.
Surface Represents a response depending on more than one variable.
Formula Evaluates a response from a configured mathematical expression.
Compiled Uses a compiled implementation for the response calculation.

Scope and Conditions

Dials do not necessarily apply to every event. Their configuration can determine which events, samples, or categories receive a particular systematic response.

This makes it possible to associate different model responses with different regions of the analysis while still using the same parameter framework.

Multiple Dials

An event can be affected by more than one dial. When multiple systematic effects apply, their responses are combined when the event prediction is propagated.

Event
→
Dial A
Dial B
Dial C
→
Modified prediction

Example Structure

A simplified configuration may associate a parameter with a dial definition such as: 

dialSetDefinitions:

  - name: exampleDial

    dialType: Spline

    applyCondition:
      sample: exampleSample

    dialInput:
      file: path/to/response.root

This example is intended to illustrate the documentation structure. The final reference should use the exact option names and schema from the current GUNDAM configuration documentation.
