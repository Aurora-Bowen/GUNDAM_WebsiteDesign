CONFIGURATION REFERENCE

Samples

Samples define how events are grouped for the fit. A Sample Set contains the list of fit samples and determines the statistical likelihood function used to compare model predictions with data.

Sample Set

The Sample Set collects the sample definitions used by the propagator and specifies the statistical likelihood function.

Option Type Description Default
fitSampleList list(json) List of Sample configurations. —
llhStatFunction string Name of the statistical likelihood function. PoissonLLH

Likelihood Functions

The current Sample Set configuration supports several statistical likelihood implementations.

  • PoissonLLH
  • BarlowLLH
  • BarlowLLH_BANFF_OA2020
  • BarlowLLH_BANFF_OA2021
  • Plugin for a custom likelihood implementation

Fit Sample

Each entry in fitSampleList defines an individual analysis sample, including its selection, binning, datasets, and normalization.

Option Type Description Default
name string Sample name. —
isEnabled bool Include the sample in the propagator. true
binning string Path to the binning definition file. —
selectionCuts string Tree selection formula. —
datasets list(string) List of datasets that populate this sample. {"*"}
mcNorm double Global MC sample normalization. 1
dataNorm double Global data sample normalization. 1

Example Structure

A Sample Set can contain multiple entries in fitSampleList. 

sampleSetConfig:
  llhStatFunction: PoissonLLH

  fitSampleList:
    - name: exampleSample
      isEnabled: true
      binning: path/to/binning.yaml
      selectionCuts: "selection_expression"
      datasets:
        - "*"
      mcNorm: 1
      dataNorm: 1
