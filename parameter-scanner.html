Parameter Scanner

The Parameter Scanner evaluates the likelihood across selected parameter values to study the structure of the fit space.

What the Scanner Does

Parameter scans evaluate the likelihood while systematically varying one or more selected parameters.

Scan Variables

The scanner configuration identifies which fit parameters are scanned and defines the values or ranges over which the likelihood is evaluated.

Multiple scan variables can be used when exploring multidimensional likelihood structure.

Pre-fit and Post-fit Scans

Parameter scans can be useful before minimization to inspect the initial likelihood surface or after the fit to study the behavior around the fitted solution.

Pre-fit Scan

Explore the likelihood before the main minimization.

Post-fit Scan

Explore the likelihood around the fitted parameter solution.

Scan Output

Scanner output can be used to visualize likelihood profiles and study parameter constraints, degeneracies, or non-Gaussian behavior.
