CONFIGURATION REFERENCE

Minimizer

The Minimizer Interface controls how GUNDAM explores the likelihood and estimates fit parameters.

Two main approaches are supported: maximum-likelihood optimization using the ROOT minimizer and posterior sampling using Simple MCMC.

Minimizer Types

ROOT Minimizer

Perform numerical likelihood minimization to find the best-fit point and evaluate the covariance or Hessian near the minimum.

Simple MCMC

Generate a Markov-chain sample of the likelihood or posterior distribution.

Common Options

These options apply to both minimizer implementations.

Option Type Description Default
type string Choose SimpleMcmc or RootMinimizer. RootMinimizer
checkParameterValidity bool Enable parameter validity checks. false
showParametersOnFitMonitor bool Display fit-parameter values on the fit monitor. false
enablePostFitErrorFit bool Apply error evaluation after minimization. true
maxNbParametersPerLineOnMonitor int Maximum number of parameters displayed on one monitor line. 15
useNormalizedFitSpace bool Use normalized parameter coordinates with prior mean 0 and standard deviation 1. true
writeLlhHistory bool Write a TTree containing likelihood evaluations. false

ROOT Minimizer Options

Option Type Description Default
minimizer string ROOT minimizer engine. Minuit2
algorithm string Algorithm used by the selected minimizer. Engine default
errors string Error algorithm applied after the fit, such as HESSE or MINOS. Hesse
tolerance double Required estimated distance from the minimum for fit convergence. 1E-4
maxFcnCalls int Maximum number of likelihood function calls. 1E9
maxIterations int Maximum number of minimizer iterations. 500
strategy int ROOT minimizer strategy. 1
enableSimplexBeforeMinimize bool Run SIMPLEX before the main minimization. false

Simple MCMC

Simple MCMC generates a chain of points drawn from the likelihood and can be used to characterize a multidimensional posterior distribution.

Because the MCMC configuration has substantially more options and workflow-specific behavior, it is kept as a separate detailed reference page.

Configure chains, burn-in, proposal behavior, cycles, output, and MCMC-specific settings.
