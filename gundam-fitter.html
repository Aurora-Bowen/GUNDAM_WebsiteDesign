Main Workflow

gundamFitter

The main GUNDAM application for performing fits to experimental or simulated data.

Quick Start

Run a fit

Most inputs are provided through a YAML or JSON configuration file. 

gundamFitter -c path/to/config.yaml

Configuration

How the configuration enters the fitter

The fitter configuration is passed to the Fitter Engine, which coordinates the likelihood, minimizer, and optional parameter scanner.

Command Line

Common options

The detailed command-line options remain part of the technical reference.

Option Purpose
-c Path to the main configuration file.
-t Configure the number of parallel threads.
--dry-run Prepare the fit without performing the full minimization.
