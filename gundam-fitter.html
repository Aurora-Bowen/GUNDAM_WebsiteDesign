gundamFitter

The main GUNDAM application for performing fits to experimental or simulated data.

Quick Start

Most inputs are provided through a YAML or JSON configuration file. 

gundamFitter -c path/to/config.yaml

Configuration

The fitter configuration is passed to the Fitter Engine, which coordinates the likelihood calculation, minimization, and parameter scanning.
