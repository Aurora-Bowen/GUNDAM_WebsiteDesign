CONFIGURATION REFERENCE

Parameters

Fit parameters are organized into parameter sets. A parameter set defines a related group of parameters, while each individual parameter defines its nominal value, fit behavior, limits, and associated systematic response.

Parameter Sets

Parameter sets group related fit parameters and define configuration that applies to the group as a whole.

Parameter Definitions

Each parameter definition describes one fit parameter inside the set.

Typical information includes the parameter name, whether it is enabled or fixed, its prior value, allowed range, and other fit settings.

Concept Purpose
Name Identifies the parameter.
Prior value Defines the nominal or prior parameter value.
Fit state Controls whether the parameter is enabled, fixed, or varied by the fit.
Limits Defines the allowed parameter range.

Covariance and Correlations

Parameter sets can use covariance information to describe uncertainties and correlations between parameters.

Dials

Parameters affect the model through dial definitions. Since dials are reusable and have their own detailed configuration, they remain a separate reference page.
