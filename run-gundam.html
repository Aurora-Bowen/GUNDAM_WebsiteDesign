USER GUIDE

Run GUNDAM

Run GUNDAM provides guidance for using the main GUNDAM applications and connects each workflow to the shared configuration reference.

MAIN WORKFLOWS

Run an analysis

Start with the application that matches the task you want to perform.

gundamFitter

Perform fits to experimental or simulated data using GUNDAM.

gundamCalcXsec

Perform cross-section calculations using GUNDAM analysis outputs.

CONFIGURATION UTILITIES

Prepare and inspect configurations

These utilities help prepare, compare, and package GUNDAM configuration inputs.

Config Unfolder

Expand related configuration files into a single configuration.

Config Compare

Compare two GUNDAM configurations.

Input Zipper

Package configuration inputs and related files.

FIT OUTPUT UTILITIES

Inspect and compare fit outputs

Output utilities provide tools for reading, comparing, plotting, and extracting fit results.

Fit Reader

Load and inspect fit results.

Fit Compare

Compare fit results and visualize differences.

Fit Plot

Create plots from GUNDAM fit outputs.

Plot Extractor

Extract plots and related fit information.

CONFIGURATION REFERENCE

Configure the fit

The configuration reference explains how the major GUNDAM components are connected and how their options control the analysis.

Fitter Engine

Configure likelihood evaluation, minimization, and parameter scanning.

Likelihood

Configure datasets, model propagation, and likelihood calculation.

Propagator

Configure samples, parameters, dials, and propagation of systematic effects.

Minimizer

Configure numerical minimization or MCMC sampling.
