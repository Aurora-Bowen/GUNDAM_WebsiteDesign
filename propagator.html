Propagator

The Propagator applies fit-parameter variations to the analysis model. It connects parameter definitions with the samples that are used to construct the model prediction.

Main Structure

The Propagator sits between the fit parameters and the analysis samples.

Samples

The sample configuration determines how events are grouped for the fit and how the resulting model prediction is compared with the data.

Samples

Configure the Sample Set, individual fit samples, statistical likelihood functions, selections, binning, and normalization.

Parameters

Parameter sets define the quantities that can be varied during the fit. Their associated dials determine how those variations modify the model.

Parameters

Configure parameter sets, individual parameter definitions, covariance information, limits, and associated dials.

Event and Data Loading

The Propagator also coordinates the event information needed to construct the samples and evaluate parameter responses.

In the redesigned documentation, data-loading details can remain part of the Propagator page unless they become large enough to justify an independent reference page.

Configuration Reference

The original Propagator configuration table will be preserved here as the authoritative technical reference.

Configuration Area Purpose
sampleSetConfig Configure the samples used to construct and compare model predictions.
parameterSetListConfig Configure the parameter sets whose variations are propagated through the model.
