DIAL REFERENCE

Tabulated Dials

Tabulated dials evaluate a model response from precomputed values stored in a lookup or interpolation structure.

Configuration

A tabulated dial connects a parameter variation to precomputed response information.

Parameter
→
Tabulated Dial
→
Lookup / interpolation
→
Event response

External Library

Tabulated dials can use an external compiled library to initialize the lookup structure and evaluate the response.

Function Role
initFunction Initializes the tabulated response data.
updateFunction Updates response information when required.
binningFunction Determines the lookup/binning information associated with an event.

Lookup and Interpolation

Event variables are used to locate the corresponding entry in the tabulated response. Depending on the configuration, interpolation can be used between stored response points. 

Event variables
      ↓
Lookup bin
      ↓
Stored response
      ↓
Interpolation
      ↓
Dial weight

Compiling the Library

When an external implementation is used, the library must expose the functions expected by the tabulated dial configuration and be available to GUNDAM at runtime.

The final documentation will preserve the exact function signatures and compilation instructions from the existing GUNDAM reference.
