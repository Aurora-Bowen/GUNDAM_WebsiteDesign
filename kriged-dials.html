DIAL REFERENCE

Kriged Dials

Kriged dials use kriging-based interpolation to estimate model responses from a set of known response points in a multidimensional variable space.

Configuration

A kriged dial associates event variables with a collection of known response points and evaluates an interpolated response for each event.

Kriging Concept

Kriging estimates the response at an unknown point by combining nearby known responses with weights derived from their relationship in the input variable space.
