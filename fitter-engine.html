CONFIGURATION REFERENCE

Fitter Engine

The Fitter Engine coordinates the main components used to perform a GUNDAM fit, including likelihood calculation, minimization, and parameter scanning.

Main Structure

The top-level fitter configuration connects three main components.

FitterEngineConfig
→
Likelihood
model and data comparison
Minimizer
fit or sampling procedure
Parameter Scanner
parameter scans

Main Configuration

These configuration objects define the main behavior of the Fitter Engine.

likelihoodInterfaceConfig

Configure datasets, the model propagator, and likelihood calculation.

minimizerConfig

Configure the minimization or sampling method.

parameterScannerConfig

Configure scans over fit parameters.

Configuration Reference

The detailed configuration table is preserved as the authoritative reference.

Option Type Description Default
likelihoodInterfaceConfig json Configure the likelihood calculation. —
minimizerConfig json Configure the Minimizer Interface. —
parameterScannerConfig json Configure parameter scanning. —
enablePreFitScan bool Run a parameter scan before minimization. —
enablePostFitScan bool Run a parameter scan after minimization. —
